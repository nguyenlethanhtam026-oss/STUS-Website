STUS — WEBSITE DEMO
===================

Cách chạy:
1. Giải nén file stus_website_demo.zip.
2. Mở thư mục stus_website.
3. Nhấp đúp vào index.html (hoặc chuột phải > Open with > Chrome/Edge).
4. Website chạy trực tiếp trên trình duyệt, không cần cài đặt thêm.

Chức năng demo:
- Responsive desktop/mobile.
- Tìm kiếm, lọc theo môn học, khối lớp và loại tài liệu.
- Xem chi tiết sản phẩm.
- Thêm/xóa sản phẩm và chỉnh số lượng trong giỏ.
- Thanh toán mô phỏng.
- Thư viện tài liệu demo.
- Lưu giỏ hàng/thư viện trên trình duyệt bằng LocalStorage.

Lưu ý:
- Giá và sản phẩm là dữ liệu giả định phục vụ bài tập.
- Không có cổng thanh toán thật, không thu tiền.
- Trang đọc và ảnh bìa là nội dung minh họa, chưa phải tài liệu hoàn chỉnh.
- LocalStorage chỉ lưu trên trình duyệt/thiết bị hiện tại; xóa dữ liệu trình duyệt có thể làm mất dữ liệu demo.
- Trước khi kinh doanh thật, cần backend, xác thực tài khoản, lưu trữ file an toàn, bảo vệ dữ liệu cá nhân, điều khoản/chính sách và quyền phân phối tài liệu.
